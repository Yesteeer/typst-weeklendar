# Weeklendar

_Weeklendar_ (contraction of _week_ and _calendar_) is a Typst package for creating a calendar displayed as weekly timetables which design is based on the LaTeX Overleaf [timetable](https://www.overleaf.com/latex/templates/timetable/npdzfmychtjm) template.

## Dependencies

_Weeklendar_ uses [cetz:0.5.2](https://typst.app/universe/package/cetz/).

## Quickstart

Simply download the package locally (as described on the [Typst Packages](https://github.com/typst/packages)) repository. Then import and use Weeklendar.
